# Deenijora

দ্বীনদার পাত্র-পাত্রীর জন্য অভিভাবক-কেন্দ্রিক, ফোনে যাচাই করা বিয়ের পরিচয় সেবা।
Plain HTML/CSS/JS (no build step) + Supabase (auth + Postgres with RLS). Hosts free on GitHub Pages.

## What's inside

| Path | What |
|---|---|
| `index.html` | Landing page |
| `about/guide/contact/terms/privacy.html` | Info pages, generated by `sh build-pages.sh` |
| `app.html` + `js/` | Account app: login, dashboard, biodata editor, search, biodata page, likes/dislikes, proposals, support, settings, admin |
| `js/config.js` | **The only file you edit to go live** (Supabase URL, anon key, WhatsApp) |
| `js/db.js` | All database calls |
| `js/mock.js` | Demo data, used automatically until `config.js` is filled in |
| `supabase/schema.sql` | Tables, RLS policies, RPCs — run once in Supabase |
| `supabase/test/run.sh` | 23 security tests on a throwaway local Postgres |

## Privacy model (enforced in the database, not the browser)

- `biodatas`: non-identifying info. Visible only to **logged-in** users and only once an admin **approves** it.
- `biodata_private`: name + both phone numbers. Visible **only to the owner and admins**. Never sent to other users.
- Users cannot approve themselves; editing an approved biodata sends it back to review.
- Interest flow: A (approved biodata required) → B accepts/declines → admin calls both guardians → marks "introduced". Contacts are never exchanged automatically.
- Who-liked-me and view counts are aggregated server-side; identities stay hidden.

## Go live (≈30 minutes)

1. **Supabase project**: create a free project at supabase.com (region: Singapore is closest to Bangladesh).
2. **Database**: Dashboard → SQL Editor → paste all of `supabase/schema.sql` → Run.
3. **Email login**: with Supabase's default email the user gets a login **link** (works as-is). To send a 6-digit code instead, first set up custom SMTP (step 5), then put `{{ .Token }}` in both the "Confirm signup" and "Magic link or OTP" templates.
4. **URLs**: Authentication → URL Configuration → Site URL `https://deenijora.com`, add `https://deenijora.com/app.html` to Redirect URLs.
5. **SMTP** (important): Supabase's built-in email is rate-limited to a few emails/hour. Authentication → SMTP Settings → add a provider (Resend, Brevo, Amazon SES).
6. **Config**: Project Settings → API → copy *Project URL* and *anon public* key into `js/config.js`, and set your WhatsApp number (`8801XXXXXXXXX`). Then run `sh build-pages.sh` so the info pages pick up the number, and replace `8801XXXXXXXXX` in `index.html`.
7. **Make yourself admin**: log in once on the site, then in SQL Editor:
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'you@example.com');
   ```
8. **Custom domain**: point deenijora.com DNS at GitHub Pages (A records 185.199.108.153, .109.153, .110.153, .111.153; CNAME `www` → `mazharulhridooy.github.io`), then `git mv CNAME.disabled CNAME`, push, and tick "Enforce HTTPS" in Settings → Pages. (CNAME is disabled until DNS is ready, otherwise the github.io address redirects to a dead domain.)

## Try it without Supabase (demo mode)

```bash
python3 -m http.server 8765
```
Open http://localhost:8765/app.html — login code is `123456`; an email starting with `admin` gets the admin panel. Demo data lives only in that browser.
